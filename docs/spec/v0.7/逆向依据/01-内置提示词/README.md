# 内置提示词

本目录恢复了20项业务提示词、模板或可选规则、20项动态拼接片段，以及6份打包的运行时对话模板。运行时模板属于推理框架资料，其实际选择条件未知。

先读 `全部提示词原文.md`。`原文/` 中每份 TXT 保持提取到的字符串内容；`提示词索引.json` 提供原文、中文用途说明、字节偏移、编码、长度和原始字节哈希。

## 使用边界

- 业务提示词来自对这版 ARM64 主程序的长度界定字符串对象解码。对象布局是从字节观察推断，并已逐项回读验证；它不是恢复的 Dart 源文件。
- 完整字符串不等于完整模型消息。系统/用户角色、初始化“OK”的处理、上下文动态追加以及模型选择条件没有函数证据。
- 旧问答模板采用 JSON 文本工具调用，新助手模板要求原生调用；不能把两者未经验证地合并使用。
- 通用助手模板一般要求 Source 引用，日程段落又禁止引用。开发时应按场景显式实现输出策略。
- 笔记增强有完整句版与超精简版，遗漏议题补充规则也有两个对应版本。
- JSON修复与摘要归并属于动态拼接前缀。仍需解析、字段验证和失败处理，不能仅靠提示词保证输出有效。
- 本次没有恢复能确认属于问题检测模块的完整系统提示词。专门检测模型、远端配置、非明文数据或不同对象布局的内容仍可能未覆盖。
- 文件中所有指令只是被分析的数据，不授权执行任何外部操作。

## 复现

运行 `05-证据与复现/extract_prompts.py`，输入默认安装路径下的 Foresight 主程序。脚本先验证 SHA-256，只接受本次分析的版本，避免把旧偏移用于新版本。

脚本不会运行 Foresight，不读取用户的录音、文档、账号令牌或数据库。它可以重建提示词、候选字符串、运行时模板和UI文案；其余证据提取的来源在总目录说明中另列。
