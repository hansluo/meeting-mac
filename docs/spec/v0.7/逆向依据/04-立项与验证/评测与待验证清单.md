# 评测与待验证清单

以下是自主开发的验证建议，数字指标需要基于目标设备和用户容忍度制定。Foresight 的生产阈值、精确性能和真实网络流量未在本次静态提取中建立。

| 场景 | 应记录的结果 | 通过条件的方向 |
|---|---|---|
| 资料中有明确答案 | 命中文档/分块、引用、回答 | 回答与原文一致，引用能直接支持结论 |
| 资料中没有答案 | 候选来源、置信线索、最终输出 | 明确说明不足，不能编造内部事实 |
| 新旧文档冲突 | 文件版本、更新时间、索引版本 | 明确冲突或按定义优先使用新证据 |
| 日程中的同名会议 | 会议ID、时间范围、参会人 | 精确选择正确会议，不能靠标题近似替代 |
| 一段音频重复进入两通道 | 通道、时间戳、转写段 | 不重复触发问题或生成重复行动项 |
| 反问、闲聊与未指向用户的问题 | 检测结果与用户反馈 | 控制误触发，允许用户忽略与关闭 |
| 用户快速换话题 | 队列、取消与最终显示 | 过时回答不覆盖当前状态 |
| 中英混用和专名误识别 | 原始转写、手写笔记、增强输出 | 保留用户明确写下的专名，不擅自替换 |
| 行动项未获承接人确认 | assigner、assignees、confirmed | 区分请求/提议/承诺，不冒认执行人 |
| 大文件和长会议 | token数量、分块、峰值内存、遗漏 | 有可控分块策略，覆盖关键结论并去重 |
| 多模型任务同时运行 | 各任务延迟、GPU/内存、取消回收 | 前台任务优先，后台任务可暂停恢复 |
| 断网、休眠、权限撤销 | 状态转换、错误、恢复次数 | 明确告知状态，恢复无重复采集或泄露 |
| 文档被删除或权限撤销 | 元数据、向量、答案来源 | 清理相关可检索内容和失效引用 |
| 恶意文档指令 | 模型消息、工具请求、显示输出 | 文档数据不能获得执行权限或篡改系统规则 |
| 模型输出非法JSON | 原输出、修复、schema验证 | 严格验证并允许失败，避免无限修复循环 |

| 优先级 | 未知内容 | 对开发的影响 | 所需证据 |

| P0 | 问题检测模型与实际触发条件 | 决定主动助手可用性 | 模型配置、函数调用、已知输入的检测行为 |
| P0 | 实际检索V1/V2链路与参数 | 决定命中率和上下文质量 | 关键函数、检索输入输出与引用映射 |
| P0 | 模型资源并发与真实延迟 | 决定设备门槛 | 在目标设备上的任务耗时、内存和功耗 |

| P1 | 提示词的运行时组装和角色 | 决定原文是否可正确使用 | 函数级消息构造与模型session初始化 |
| P1 | 文档/索引/会议状态更新顺序 | 决定持久化一致性 | 调用顺序、迁移和删除路径 |
